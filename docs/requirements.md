# Требования и доказательства завершения

Дата основания: 2026-09-08. Источник: исходная задача пользователя.
Статус: работа начата с пустой директории; Git инициализирован.

## Обязательная продуктовая цель

Агент из любого harness с доступом к установленному интерфейсу получает skill,
собирает workflow из блоков и связей, настраивает роли и запускает его на pi.
Агенту не требуется писать код оркестрации, циклы или функции маршрутизации.
Система машинно генерирует TypeScript + Effect по проверенной схеме.

## Открытые уточнения, влияющие на устройство

Пользователь выбрал сборку схемы перед запуском, условия/циклы и динамический fan-out.
Runtime не редактирует топологию активного run; pause поддерживается отдельно.

Ответы и выбранные defaults закреплены в docs/decisions.md; фактические результаты
проверок перечислены в таблице и профильной документации.
«Любой harness» означает независимый backend и опубликованный контракт для клиента,
умеющего прочитать инструкции и вызвать CLI/MCP. Два успешных клиента подтверждают
две интеграции, а не совместимость со всеми существующими или будущими продуктами.

## Порядок проверки результата

1. Контрактные проверки authoring и компилятора: ошибки схемы, стабильность генерации,
   соответствие рёбер, портов и замороженных настроек.
2. Детерминированные сценарии runtime: fan-out/join, циклы, ошибки, cancel,
   лимиты, проверка выходов, конкурентные изменения и восстановление.
3. Интеграция с настоящим pi: применённые model/tools/skills/system prompt,
   вывод по схеме и прерывание процесса. Mock-only тесты это не доказывают.
4. Полный пользовательский путь: подключить skill, инструментами собрать схему,
   запустить, увидеть стадии, исправить по ревью, сохранить и повторить preset.
5. Проверить все строки таблицы по актуальному дереву, выводам команд и runtime.
   Не маркировать весь проект завершённым по одному зелёному тестовому набору.
