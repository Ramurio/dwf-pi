# E09 — изоляция повреждённых preset

`PresetLibrary.names/hasName` обнаруживают имена независимо от исправности
ревизий. `scan(name)` возвращает `{ records, diagnostics }`: records проходят
прежние проверки JSON, структуры, frozen plan, hash и symlink; ошибка одного
файла не прерывает остальные. `versions` возвращает проверенные records;
для диагностики используйте `scan`.

`preset.list` остаётся массивом. Для здорового имени формат прежний (latest).
Для повреждённого имени выдаются все проверенные ревизии с `latest: false`
(это означает отсутствие гарантии latest) и отдельные элементы:

```
{ kind: "diagnostic", name, revision, reason, scope, directory, shadowed }
```

`revision: null` обозначает ошибку каталога имени. Причины ограничены
безопасными сообщениями: исходный JSON, содержимое плана и произвольные
сообщения файловой системы не публикуются. Scope и directory добавляет service.

Неявное чтение повреждённого имени требует явного hash, даже если найдена
здоровая ревизия. Явное чтение проверяет только выбранный файл, без versions
как предварительного gate. Project затеняет global по наличию имени, включая
пустое, повреждённое или symlink-имя; ошибки и отсутствующий hash не вызывают
fallback. Явный `scope: global` по-прежнему разрешён.

Проверено: 11 тестов в `preset-corruption.test.ts`, `presets.test.ts`,
`service.test.ts`; `npm run typecheck`. Новая регрессия использует только
локальный no-model план: повреждённые старый/потенциальный latest JSON,
полностью повреждённое имя, соседнее здоровое имя, несовпадение hash,
symlink файла/каталога, inspect/run по здоровому hash и запрет scope fallback.
AGENTS.md в worktree и его родительских каталогах отсутствует.
