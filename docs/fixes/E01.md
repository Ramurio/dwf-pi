# E01 — публичная схема patch

В `authoring.ts` добавлена PublicDraftPatchSchema: обязательные id,
expectedRevision и operations, запрет дополнительных полей. Её возвращает
workflow.schema и использует MCP. Общая нормализация рекурсивных JSON Schema
вынесена из mcp-tools в public-schema.ts: service не импортирует MCP, цикла нет.
DraftPatchSchema и контракт DraftStore.patch остались внутренними, без id.

## Проверки

- `npm run typecheck` — успешно.
- `node --import tsx --test tests/public-patch-schema.test.ts tests/skill-handoff.test.ts tests/authoring.test.ts tests/cli.test.ts tests/mcp.test.ts` — 19/19.
- Реальные CLI subprocess и официальный MCP stdio client выполняют schema →
  create → patch → validate → prepare → start (preparedId/idempotencyKey).
  MCP tools/list сравнивается с возвращённой service схемой без нормализации
  в тесте. Проверены обязательный id, лишние поля и внутренний контракт.
- Временные отдельные SQLite stores; граф только await/end, без моделей,
  провайдеров, credentials и внешних команд. Await удерживает запуск незавершённым:
  первый run.status проверяется немедленно, без ожидания завершения. Проверены
  реальный run id, planHash и идемпотентный повтор start. Затем run отменяется.
- Конверты запросов/ответов сохраняются в памяти и во временный envelopes.json,
  перечитываются и сравниваются; MCP text и structuredContent идентичны.
  Временные артефакты удаляются вместе со store после остановки запуска.
- Негативные handoff-проверки обоих транспортов сохраняют operationIndex=1,
  expectedRevision=1/actualRevision=2; неудачный batch не меняет revision и граф.

## No-change и границы доказательств

`src/cli.ts` и `src/mcp.ts` — no-change: оба уже сериализуют operationIndex
и expectedRevision/actualRevision. Регрессионные тесты подтверждают фактические
транспортные конверты, а не только исходный код.

Уточнён только repository skill, установленный глобальный skill не менялся.
Packet E01 прочитан; AGENTS.md в worktree и проверенных родительских каталогах
отсутствует. Frozen runner, кампания и чужие журналы не менялись.

Это scripted offline handoff, а не доказательство безошибочного первого запуска
новым агентом. Проверка новым живым агентом не выполнялась: подагенты и вызовы
провайдеров запрещены условиями задачи.
